# Diário de decisões

Copie este arquivo para `decisoes.md` (o real fica fora do git) ou crie a primeira decisão com:

```powershell
npm run diario -- novo "comprar mais 2 cotas de XPTO3"
```

Preencha `tese`, `espero` e `provacao` **antes** de decidir. Quando chegar a data em
`revisarEm`, o `npm run diario` mostra o que você escreveu ao lado do que o mercado fez:
quanto o ativo andou desde então e quanto o CDI rendeu no mesmo período. Aí você escreve o
que aprendeu em `revisado` e a decisão sai da fila.
