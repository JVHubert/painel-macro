# Trilha de estudo

Copie este arquivo para `respostas.md` (o real fica fora do git) e, a cada domingo:

```powershell
npm run estudo -- novo    # cria o bloco da semana com a pergunta
npm run estudo            # mostra a pergunta da semana, o que falta e o placar
```

Responda **primeiro sem ajuda**, com as suas palavras. Só depois abra o `PROMPT.md` e peça a
correção — é o erro que você tenta explicar que faz a resposta colar.
