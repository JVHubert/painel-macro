# Trilha de estudo

Copie este arquivo para `respostas.md` (o real fica fora do git) e, a cada domingo:

```powershell
npm run estudo -- novo                  # cria o bloco da semana com a pergunta
npm run estudo -- responder 1126,83     # registra a resposta e corrige na hora (perguntas de conta)
npm run estudo                          # mostra a pergunta da semana, o que falta e o placar
```

Responda **primeiro sem ajuda**, com as suas palavras. Só depois abra o `PROMPT.md` e peça a
correção — é o erro que você tenta explicar que faz a resposta colar.

Aceita vírgula ou ponto na resposta (`1126,83` ou `1126.83`, com ou sem `R$`). Nas perguntas de
conta o sistema confere sozinho, com 1% de tolerância, e escreve o gabarito no bloco para a
correção não mudar depois. Nas de conceito, quem corrige é o professor: escreva o resultado em
`corrigido:` (`certo`, `parcial` ou `errado`, e o comentário depois de ` — `).
